# My Portfolio

A personal portfolio website built with TypeScript and CSS.

## About
This repository contains a simple, modern portfolio site showcasing projects and skills. It's implemented primarily in TypeScript with a small amount of CSS.

## Tech Stack
- TypeScript
- CSS

(Repo language composition: TypeScript ~98%, CSS ~2%)

## Getting Started
Prerequisites:
- Node.js (v16+ recommended)
- npm or yarn

Install dependencies:

```bash
npm install
# or
# yarn install
```

Run the development server:

```bash
npm run dev
# or
# yarn dev
```

Build for production:

```bash
npm run build
```
